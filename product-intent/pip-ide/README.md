# PIP IDE Product Intent Package

This package is the modeled product intent for the PIP IDE 0.1 draft. It defines
one canonical Product Intent Package with several synchronized human views.
It is not build-ready. Open authority and release questions remain in
`governance/questions.yaml`.

## Confirmed direction

- The product helps people turn thoughts into a Product Intent Package and read
  an existing package.
- One canonical package feeds the experience board, semantic canvas, structured
  record view, data table, task overlay, and product-agent chat.
- The product includes a Linear-style task manager and product-agent chat.

## Proposed direction

- Agent changes stay as proposals until an authorized person approves them.
- Tasks link execution to intent but do not become product intent.
- The first product uses a purpose-built application shell. A VS Code extension
  may follow later.

## Draft use

Read the YAML registries and Markdown diagrams together. Stable IDs connect the
structures through `verification/traceability.yaml`. External links in
`governance/evidence.yaml` are evidence only. They do not replace confirmed
intent in this package.

The package uses YAML for structured records. Mermaid diagrams use fenced blocks
in Markdown files so common editors can render them.

The current [Figma workspace concept](https://www.figma.com/design/NMUiwN7LaOsPrsQO3KPP4W/IP-IDE-Experience?node-id=4-17)
is a low-fidelity proposal. It needs Design Lead review.
